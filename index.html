Who is using this copy

The key is stored in this browser on this machine only. It is never written into an export, so sharing your matter list never shares the key. Each person enters their own.

Data

This copy stores matters in this browser. To work from the same list, one person exports a handoff file and the other opens it — matching dockets update in place rather than duplicating.

Shared folder sync

Connect a folder — e.g. a spot on the firm's S: drive — and this browser keeps a shared file there up to date automatically: on every change you make, and every couple of minutes in the background, so you also pick up everyone else's edits without doing anything. It merges rather than overwrites, so it can't silently erase someone's newer edit or bring back something that was deleted. Everyone who wants to share data points this at the exact same folder. Chrome or Edge only.

Google Calendar

Pushes each matter's calendar-worthy dates — file-motion-by, discovery end date, arbitration, trial, statute of limitations — to a shared Google Calendar automatically, the moment a document read or a manual edit is saved. Needs a one-time Google Cloud setup by an admin before it can be used at all (see the README); until that's done this stays off.
